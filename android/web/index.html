01 / CONNECTIONOpenAI API 연결

API 키 상태 확인 중

키는 이 기기의 Android Keystore로 암호화해 보관합니다. 저장된 키는 화면에 다시 표시하지 않습니다.

이 기기에 저장한 API 키를 삭제할까요? 새 생성과 이어하기에는 키를 다시 저장해야 합니다. 저장된 자막은 유지됩니다.

테스트 접근 코드에는 개인 OpenAI API 키를 입력하지 마세요. 실제 오디오와 자막 텍스트를 입력한 테스트 서버를 거쳐 OpenAI로 전송합니다. 개인 API 계정에는 요금이 청구되지 않으며, 서버의 공유 사용량 한도로 중단될 수 있습니다.

코드는 기기에서 암호화해 보관하며 화면에 다시 표시하지 않습니다.

이 기기의 테스트 서버 주소와 접근 코드를 삭제할까요? 테스트 서버로 만든 미완료 작업은 같은 서버를 다시 연결해야 이어할 수 있습니다. 개인 API 키와 저장된 자막은 유지됩니다.

연결 확인은 현재 연결의 인증과 선택 모델 접근만 검사합니다. 결제 상태나 잔액은 확인하지 않습니다.

02 / DEFAULTS다음 영상의 기본 설정
모델 설정 · 고급

GPT Transcribe는 약 30초 단위로 작업하지만 자막 시각은 추정값입니다. 화자 자동 구분 모델의 인물 ID는 작업 구간별로 다를 수 있습니다.

기본 번역 모델은 gpt-6-luna입니다. 계정에서 사용할 수 있는 모델 이름을 입력하세요.

번역 모델: gpt-6-luna

Whisper와 화자 구분 모델은 2027년 2월 26일 지원 종료 예정입니다. 정확한 시간 싱크를 중시하면 기존 Whisper를 사용하고, 새 GPT 모델 결과는 영상과 비교해 시간을 수정하세요.

저장한 설정은 새로 선택하는 영상에 적용됩니다.

03 / DATA전송 데이터 · 비용 · 이어하기

전송 데이터

파일 자막 생성 시 영상에서 추출한 오디오 구간과 번역에 필요한 자막 텍스트만 선택한 API/테스트 서버로 전송됩니다. 원본 영상 파일 자체를 클라우드에 보관하는 기능은 없습니다. 기기 온디바이스·Vosk 인식은 별도 실행 방식입니다.

요금 및 사용량

개인 API는 본인 OpenAI 계정으로 실제 요청한 만큼 청구될 수 있습니다. 연결 확인은 결제 상태·잔액·월 누적 비용을 조회하지 않습니다. 테스트 서버는 해당 서버의 공유 사용량 한도를 적용합니다.

작업 이어하기

처리한 구간과 자막이 기기에 저장된 경우 남은 구간부터 수동으로 이어할 수 있습니다. 강제 중지·재부팅 후에는 앱을 다시 열고 작업 관리에서 '이어하기'를 선택하세요. 자동 재시작 기능은 제공하지 않습니다.

원본 파일

원본 파일을 이동하거나 삭제하면 이어하기와 미리보기가 불가능할 수 있습니다.
