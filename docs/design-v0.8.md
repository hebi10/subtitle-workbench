# Subtitle Workbench · v0.8 화면 리디자인 가이드

## 목적과 범위
기존 기능·경로·내보내기 포맷을 유지하면서 웹과 Android 화면의 정보 구조를 정돈합니다. 주요 사용자 흐름은 웹 **생성 → 편집 → 내보내기**, Android **영상 추가 → 작업 → 결과 → 설정**이며, Android의 **자막 편집**과 **온디바이스/유료 GPT 실시간 마이크**는 기존 흐름 안에서 접근합니다.

## 화면별 정보 구조
1. **공통 헤더**: HB 워드마크, 해비 자막, Subtitle Workbench 설명. Android 앱에는 원본·번역·편집 기능을 안내합니다.
2. **웹 생성**: 파일 선택(명확한 점선 영역) → 연결 방식 → 언어/고급 설정 → 실행 버튼 → 상태 단계/진행률/미리보기. 긴 폼이 작업 상태를 가리지 않도록 좁은 화면에서 세로 순서로 배치합니다.
3. **웹 편집**: 검색·검수/싱크 도구 → 실행 취소/다시 실행 → 시간/원문/번역 카드 → 옆의 미리보기. 600px 이하에서는 카드가 한 열이 됩니다.
4. **웹 내보내기**: SRT/VTT/JSON 안내 및 다운로드 카드, 번역 오류·로그는 별도 영역으로 유지합니다.
5. **Android 영상 추가**: 파일 선택·자막 불러오기 → 무료 온디바이스 마이크/유료 GPT 실시간 마이크 → 연결 상태·기본값 → 준비된 작업.
6. **Android 작업**: 진행/준비/완료/오류 상태를 동일한 카드로 표시하고 자세한 정보는 기존 확장 영역에서 열람합니다. 기록 삭제는 기존의 2단계 확인을 유지합니다.
7. **Android 결과**: 선택한 작업과 요약, 편집·미리보기, SRT/VTT/JSON 저장.
8. **Android 편집**: 선택한 자막, 시간·화자·원문·번역·병합/분할, 검색·검수 필터와 저장 상태를 명확히 구분합니다.
9. **Android 설정·확인**: API 연결/암호화 저장/삭제 확인, 기본 모델/언어 설정, 사용 비용 및 데이터 주의사항을 동일한 카드 언어로 정리합니다.
10. **네이티브 마이크 화면**: 동일한 흑백 버튼, 폰트, 섹션 제목, 음성 결과 카드. 무료 온디바이스와 유료 GPT 실시간의 원본 전송 차이를 기존 안내로 표시합니다.

## 반응형·접근성
- 테스트 뷰포트: Android WebView **320px, 390px, 800px** / 웹 **390px, 1280px**.
- 전체 문서 가로 스크롤 방지, 작업·결과·편집 화면에서 고정 하단 메뉴 및 저장 상태가 주요 버튼을 가리지 않도록 검증합니다.
- 입력 필드에 16px 모바일 글꼴을 유지하고 모든 인터랙티브 요소에 키보드 포커스 표시를 제공합니다.
- 상태 색상만으로 의미를 전달하지 않고, 원래의 상태 문구·버튼 라벨·ARIA 영역을 보존합니다.
- Android 에뮬레이터 화면과 브라우저 스크린샷은 **테스트용 화면**입니다. 실제 영상의 자막 정확도·실시간 마이크 네트워크 호출 검증을 뜻하지 않습니다.

- \`android/app/build.gradle\` 버전코드 8 / 버전명 0.8.0
