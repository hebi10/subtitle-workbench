# Editorial Studio 2.0 · 2-B Android 작업 관리 화면

## 목적
기존 `jobsView` 화면에서 진행·대기·준비·일시정지·완료·오류 작업의 **실제 상태**, 최근 처리 정보, 다음 가능한 행동이 눈에 들어오도록 재배치한다. 2-A에 이어 적용하지만 음성 인식·복구·파일 저장·네트워크·Native Bridge·SQLite 로직은 변경하지 않는다.

## UI 구성
1. 상단 `작업 관리`와 `새 작업` / `새로고침`. 새 작업 버튼은 기존 `show('video')`를 사용하며 신규 생성 프로세스는 만들지 않는다.
2. 기존 `jobsSummary`를 그대로 유지. `jobs` 배열에서 계산되는 전체·진행·준비·일시정지·완료·오류 개수는 추측·가상 수치로 대체하지 않는다.
3. 각 작업 카드: 파일명 → 상태 배지(한글 텍스트)·실제 길이/구간 → 처리 진행률·저장된 결과 기준 → 현재 단계·오류 → 주요 동작 → 펼쳐 보는 처리 상세.
4. 상태별 대표 동작:
   - 진행/대기: **일시정지**. 읽기 전용 자막 보기·결과 보기는 계속 제공.
   - 준비: 기존 `생성 시작`/준비 확인 유지.
   - 일시정지: 기존 `이어하기` 강조, API 연결 불일치 시 비활성.
   - 완료: **자막 편집** 강조, 결과 보기·SRT 저장·기록 삭제 유지.
   - 오류: 실제 연결/목적지가 일치해 재개할 수 있을 때만 `이어하기` 강조, 연결이 없거나 목적지가 다른 경우 `API 설정 확인` 강조.
5. 오류 메시지·연결 목적지 불일치 경고는 읽기 쉬운 경고 표면에 표시하며 비밀번호/토큰을 새로 노출하지 않는다. 상세 설정·비용 안내는 `details`를 유지한다.
6. 320/390px 모바일은 카드 행동 2열, 620px 이상은 3열. 0px 모서리·그림자 없음·기존 밝은/어두운 회색 팔레트 유지.

## 기존 기능과 제약
- 정렬/페이지당 4개/현재 페이지 보존(`jobPriority`, `JOBS_PAGE_SIZE`, `reconcileChildren` 그대로).
- `preparedJobs`는 `videoView`의 기존 입력 초안(준비 작업)을 계속 사용. 작업 화면의 준비 작업 요약도 상태 표시만 공통화한다.
- 새로고침 중 포커스 복원, 진행 중 사용자 액션의 중복 방지, 편집 저장/실패 재시도, 원본 미디어 유지 및 삭제 확인 등 기존 정책 보존.
- 표시되는 진행률은 `job.progress.percent` 또는 저장 완료 구간 기준. 완료 예상 시간·썸네일·클라우드 공유·필터 등 근거 없는 신규 기능은 추가하지 않는다.
- 상태 배지는 색상 외 한글 텍스트로 구분한다. 성공/경고/오류 모두 접근성 레이블과 실제 데이터로만 표현한다.

## 수정 파일
- `android/web/index.html`: 작업 헤더·기존 새 자막 작업 진입 버튼.
- `android/web/app.js`: 상태 배지 의미 정보, 상태별 대표 버튼 스타일과 실제 경로 연결; 인식 로직은 불변.
- `android/web/styles.css`: `#jobsView`에 한정한 간격·타이포·상태·오류 및 반응형 정리.
- `android/tests/editorial-2-2b-jobs.test.mjs`: 상태별 실제 데이터, 기존 액션·페이지, 가로 넘침·라이트/다크 화면.
- `.github/workflows/verify.yml`: `output/editorial-2-2b/*.png` 캡처 아티팩트 보존.

## 완료 게이트
1. 새 작업 → 영상 추가 화면 이동, 뒤로가기·4개 탭 정상.
2. 실제 상태(진행·대기·준비·일시정지·완료·오류), 저장 구간·진행률 정확.
3. 완료/재개/오류/삭제 관련 버튼은 현재 상태에 맞게 표시·활성화하며 원본 및 저장 결과를 삭제하지 않음.
4. 기존 4개/페이지 및 검색되지 않은 저장 작업 복구 유지, 폴링·포커스 안정성.
5. 320/390/800px 라이트·다크·시스템 글꼴 100/160%, 첫 화면 주요 버튼, 가로 넘침 및 키보드 상태.
6. 기존 Web·Android CI, Android 15 에뮬레이터, 디자인 캡처·모델 기반 회귀 통과.
7. CI 완료 전 병합 금지. 성공한 최종 커밋만 `main`에 Squash 병합, 제목 `[skip-play]`를 포함해 기존 AAB 중복 업로드 회피. Google Play 실제 게시·테스터 가시성은 별도 확인.
