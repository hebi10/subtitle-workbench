# Editorial Studio 2.0 · 2-F Android 네이티브 음성 인식 3종

## 목표
온디바이스 마이크(OnDeviceRecognitionActivity), GPT 실시간 마이크(CloudLiveRecognitionActivity), Vosk 오프라인 파일 인식(OfflineVoskActivity)의 준비 → 인식 → 결과 경험을 통일한다. 실제 인식 엔진, 오디오 전송, 저장·복구·언어 모델 다운로드 조건과 정책은 변경하지 않는다.

## 공통 디자인
- NativeDesignSystem.workflow는 3개 절차를 1·2·3번 순서로 표시하는 정보용 패널이다. 버튼이나 동작하는 것처럼 보이지 않으며 기존 헤더 아래에 배치한다.
- 진행 중인 단계는 무채색 대비로 강조, 지난 단계는 회색, 다음 단계는 보조 색상으로 표시한다. 모든 단계에 n단계/현재 단계/지난 단계/다음 단계 접근성 설명을 제공한다. 시스템 라이트/다크, Android 글꼴 100/160%와 0px 모서리를 유지한다.
- NativeDesignSystem.helpDisclosure: 상세 기술·시간·라이선스 설명은 접힌 상태로 두고, 탭하면 전문을 표시해 처음 실행했을 때 조작이 필요한 항목에 집중하도록 한다. Button 52dp 및 접근성 이름을 유지하고 움직임·애니메이션·그림자를 추가하지 않는다.
- 오류·진행 상태는 기존 statusPanel/transcriptPanel의 실제 상태 텍스트를 계속 사용하고, 진실하지 않은 진행률이나 예상 완료 시간을 새로 표시하지 않는다.

기기 글꼴 160%에서 3개 단계의 높이가 서로 달라지지 않도록 실제 단계 라벨은 짧은 명사형으로 표시한다: 온디바이스 `언어·인식·저장`, GPT `연결·인식·저장`, Vosk `모델·파일·전사`. 자세한 의미는 각 단계 아래의 기존 섹션 제목과 설명으로 제공한다.

## 화면별 구현
### 온디바이스 마이크
1. 언어 준비 → 마이크 인식 → 자막 저장
2. 녹음 시작·종료와 확정 자막 개수에 따라 단계 강조 이동.
3. 언어 지원 확인·시스템 모델 다운로드, Android 버전 조건, 마이크 권한, 인식 중 임시/확정 자막 분리 유지.
4. OpenAI API 키/추가 API 요금을 요구하지 않는다는 설명과 자막 시간 추정 경고는 기본 표시. 모델 도움말·저장 안내 전문은 펼쳐 읽을 수 있도록 제공한다.
5. 기록 저장은 기존 JobStore/Activity Result를 사용하며 저장 실패 재시도와 저장 전 종료 확인 유지.

### GPT 실시간 마이크
1. 연결 확인 → 실시간 인식 → 자막 저장
2. 시작 후 실제 전사 중에만 인식 단계가 강조되고, 인식 완료·오류 후 확정 자막 유무에 따라 준비 또는 결과 단계로 돌아간다.
3. 개인 API/테스트 서버의 실제 전송 대상, 사용 요금·공유 한도 및 사용자 명시적 시작 이전 전송 금지 동작 유지.
4. 최대 5분·추정 타임코드 안내를 간단히 표시하고 상세 설명은 펼쳐 읽기.
5. 화면 이탈 시 오디오 전송 종료, 권한 거절·저장 실패 안내, 자막 기록 저장 기능 유지.

### Vosk 오프라인 AI
1. 모델 설치 → 파일 선택 → 전사·저장
2. 모델 설치 여부와 실제 URI 선택에 따라 현재 단계 강조. 설치가 손상되거나 파일 선택이 없으면 원래 UI와 동일하게 버튼 활성화 제한.
3. 모델 다운로드·체크섬 검증, 설치·삭제 확인, 파일 읽기 권한, 최대 60분, 취소·진행률·자막 저장 및 미디어 URI 유지.
4. '모델 다운로드만 인터넷 필요, 음성 파일 OpenAI 미전송' 핵심 문구는 기본 표시, 인식 정확도·WER·Apache 라이선스 상세는 접힌 설명 제공.
5. 외부 모델·API/추가 네트워크 인식 기능을 도입하지 않는다.

## 변경 파일
- NativeDesignSystem.java: 공통 단계·도움말 컴포넌트.
- OnDeviceRecognitionActivity.java: 실제 녹음·결과 상태 단계와 상세 도움말.
- CloudLiveRecognitionActivity.java: 실제 연결/마이크/저장 상태 단계와 상세 비용·시간 안내.
- OfflineVoskActivity.java: 모델·파일 유무에 맞춘 단계 및 모델 품질/라이선스 안내.
- EditorialNativeScreensDeviceTest.java: 실제 Android Activity 3개를 시작하되 마이크 사용·유료 API 호출·모델 다운로드 없이 단계·도움말·버튼 비활성화 확인.

## 검증
- Gradle JVM tests·Android Lint·debug APK, Android 15 Emulator Smoke의 EditorialNativeScreensDeviceTest, MicrophoneActivityDeviceTest, OfflineVoskDeviceTest 성공.
