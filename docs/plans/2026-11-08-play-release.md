## 승인 범위
2026-11-08 사용자가 스토어 자료 등록, 초기 앱 설정, 배포 인증 연결, 내부 테스트 자동 배포, 명령 시 비공개 테스트 배포의 순차 실행을 승인했다. 대상은 hebi10/subtitle-workbench, 패키지는 com.haebi.subtitle이다.

## 결정
- 기존 Java·WebView 앱과 현재 기능을 유지한다.
- 실제 앱 캡처를 스토어 이미지의 근거로 사용하고 검증하지 않은 AI 성능을 홍보하지 않는다.
- 기존 업로드키와 인증서를 먼저 확인한다. 다른 앱의 개인키를 복사하지 않는다.
- 기본 배포는 internal, 비공개 배포는 사용자 지시에 따른 수동 실행만 허용한다.
- 이미 업로드한 내부 버전은 AAB 재업로드 없이 정확한 versionCode를 지정해 비공개 트랙으로 승격한다.
- 프로덕션 자동 배포는 제공하지 않는다. 배포 실패·생략·API 반영·게시 상태를 구분한다.
- Play 편집은 앱별 하나의 concurrency 그룹으로 직렬화한다.
