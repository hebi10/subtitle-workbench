1. 처리 방식과 전송 정보

파일 선택, 자막 편집과 기기 내 저장은 기기에서 수행합니다. 클라우드 기능은 설정에서 선택한 연결을 사용합니다. 개인 OpenAI API 연결은 아래 정보를 OpenAI로 직접 전송합니다. 선택 기능인 테스트 서버 연결은 이용자가 입력한 HTTPS 테스트 서버를 거쳐 OpenAI로 전송합니다. 테스트 서버 주소와 전용 접근 코드가 제공된 경우 이용자가 직접 연결할 수 있으며, 이 방침은 특정 서버의 배포나 현재 이용 가능 여부를 보장하지 않습니다.

기능정보와 목적외부 처리
독립 로컬 AI 파일 전사선택한 영상·음성 파일의 음성과 언어 모델을 기기에서 처리해 자막 생성설치한 Vosk 모델로 인식하며 음성·자막을 외부로 전송하지 않음. 모델 설치 시 Hugging Face 및 다운로드 제공망에 모델 요청과 연결 정보가 전달됨

개인 OpenAI 연결사용자가 입력한 API 키를 인증에 사용. 연결 확인 시 선택 모델의 접근 권한 조회API 요청의 인증 헤더로 OpenAI에 전달. 연결 확인은 음성·자막을 전송하지 않음
테스트 서버 연결전용 테스트 접근 코드로 서버 인증. 클라우드 파일 전사·번역·실시간 자막의 실제 음성·자막과 모델 설정을 선택한 서버가 처리·전달테스트 서버를 거쳐 같은 OpenAI API로 전송. 서버 전용 OpenAI API 키는 서버에만 보관하며 앱에 제공하지 않음. 개인 OpenAI API 키를 테스트 코드로 입력하지 말 것. 연결 확인은 음성·자막을 전송하지 않음

테스트 서버를 포함한 클라우드 기능과 모델 다운로드의 수신 서비스에는 통신에 필요한 IP 주소 등의 연결 정보가 전달될 수 있습니다. 앱은 IP 주소로 위치를 추정하거나 별도의 광고 식별자를 수집하지 않습니다. OpenAI, 모델 호스팅 제공자, 기기 시스템 서비스의 처리에는 해당 제공자의 정책과 사용자 계정 설정이 적용됩니다. 국외에서 처리될 수 있으며 이 앱은 국내 처리나 특정 보관 국가를 보장하지 않습니다.

2. 기기에 보관하는 정보

  • API 키는 Android Keystore의 암호키를 이용해 AES-GCM으로 암호화한 후 앱 전용 저장소에 보관합니다. 저장된 키를 화면에 다시 표시하거나 WebView에 반환하지 않습니다. 실제 API 요청에는 복호화된 키를 사용합니다. 전용 테스트 접근 코드는 개인 API 키와 분리하여 같은 방식으로 암호화하고, 저장된 코드를 화면이나 WebView에 반환하지 않습니다. 선택한 테스트 서버 주소와 연결 방식은 기기에 보관합니다.
  • 작업 이름, 선택한 파일의 접근 URI, 길이, 언어·모델 설정, 작업을 준비한 연결 방식과 테스트 서버 주소(비밀값 제외), 진행 상태, 음성 인식·번역 결과, 수정한 자막과 시간 정보를 앱 전용 SQLite 데이터베이스 등에 보관합니다. 이 데이터베이스 전체를 별도로 암호화하는 기능은 없습니다.
  • 클라우드 파일 전사 중 추출한 오디오를 앱 임시 저장소에 만들며 각 구간 처리가 끝나면 삭제를 시도합니다. 비정상 종료로 남은 오래된 오디오 임시 파일은 후속 작업 시 정리될 수 있습니다.
  • 마이크 원음은 앱이 녹음 파일로 저장하지 않습니다. 인식 문장은 해당 화면 메모리에 두며 사용자가 자막 작업으로 저장하면 작업 기록에 보관합니다.
  • Vosk 언어 모델은 앱 전용 파일 저장소에 설치합니다. 앱의 자동 백업과 기기 간 데이터 이전은 비활성화하는 설정을 적용합니다.

3. 보관 기간과 삭제

기기에 저장한 API 키, 테스트 서버 주소·접근 코드, 작업과 모델은 사용자가 삭제하거나 Android 설정에서 앱 데이터를 지울 때까지 보관합니다. 앱 삭제 시 앱 전용 데이터도 일반적으로 제거됩니다. 운영체제·기기의 동작은 해당 제공자의 정책을 따릅니다.

  • API 키: 진행 중인 파일 작업을 일시정지한 뒤 설정 → OpenAI API 연결 → 저장된 키 삭제에서 삭제합니다. OpenAI 계정의 키 자체를 폐기하려면 OpenAI 계정에서 별도로 취소해야 합니다.
  • 테스트 연결: 실행 또는 대기 중인 파일 작업을 일시정지한 뒤 설정 → OpenAI API 연결 → 테스트 서버 → 저장된 테스트 연결 삭제에서 기기에 저장한 주소와 접근 코드를 삭제합니다. 개인 API 키는 별도로 유지되며 서버에서 제공한 접근 코드 자체를 폐기하는 동작은 아닙니다.
  • 완료된 작업: 작업 → 기록 삭제 → 삭제 확인에서 저장된 자막·작업 기록을 삭제합니다. 원본 영상·음성 파일은 삭제하지 않습니다.
  • 아직 생성을 시작하지 않은 준비 작업: 준비 화면의 준비 취소로 제거합니다. 처리 도중 멈춘 기록을 포함한 모든 앱 전용 데이터는 Android의 설정 → 앱 → 자막라인 → 저장공간 → 데이터 삭제에서 지울 수 있습니다. 필요한 자막은 먼저 내보내십시오.
  • Vosk 모델: 독립 로컬 AI → 로컬 AI 모델 관리 및 파일 전사 → 다운로드한 모델 삭제를 사용합니다. 시스템 온디바이스 모델은 시스템 서비스가 별도로 관리합니다.
  • 내보낸 SRT·VTT·JSON 파일과 원본 파일은 앱 데이터 삭제로 제거하지 않습니다. 사용자가 선택한 저장소 또는 파일 관리 앱에서 직접 삭제해야 합니다. 클라우드 저장소를 저장 위치로 선택하면 해당 저장소의 정책이 적용됩니다.

테스트 서버 연결을 사용한 경우 서버는 요청 처리용 임시 오디오를 처리 종료 시 삭제하도록 구성됩니다. 비정상 종료 등의 상황에는 임시 파일이 남을 수 있습니다. 실시간 음성과 자막 내용의 영구 보관 기능은 제공하지 않습니다. 공유 사용량 한도를 유지하기 위해 서버에는 날짜·예약 사용량 등의 최소 집계 카운터가 남을 수 있으며, 기기에서 코드를 삭제해도 이 집계 기록은 삭제되지 않습니다. OpenAI에 전달된 정보에는 아래 제공자 보관 정책이 별도로 적용됩니다.

기기에서 삭제해도 이미 외부 서비스에 전송된 정보가 함께 삭제되는 것은 아닙니다. OpenAI 보관 기간과 삭제 절차는 API 종류, 계정 계약·설정과 제공자 정책에 따라 다릅니다. 번역 요청에 store: false를 사용하지만 이것만으로 모든 로그의 즉시 삭제를 보장하지 않습니다. 자세한 내용은 OpenAI API 데이터 관리 안내와 OpenAI 개인정보처리방침을 확인하십시오.

4. 권한과 이용자의 선택

  • 마이크 권한은 마이크 자막을 시작할 때 요청하며 거부하면 해당 기능을 사용할 수 없습니다. 파일 전사와 자막 편집은 별도로 사용할 수 있습니다.
  • 파일은 Android 파일 선택기에서 사용자가 선택한 항목에 접근합니다. 앱은 전체 사진·영상 보관함이나 연락처 접근 권한을 요청하지 않습니다.
  • 알림 권한은 긴 파일 작업의 진행 상태와 일시정지 동작을 알리기 위한 선택 권한입니다. 파일 처리에는 포그라운드 서비스와 일시적 화면 꺼짐 방지 권한을 사용합니다.
  • 클라우드 전사·번역·실시간 인식을 선택하지 않으면 해당 목적으로 OpenAI에 음성·자막을 전송하지 않습니다. Vosk 모델 설치 후 로컬 파일 전사와 자막 편집에는 OpenAI API 키가 필요하지 않습니다.

5. 광고, 분석과 계정

이 버전의 앱에는 광고 SDK, 광고 표시, 앱 이용 분석 또는 원격 충돌 보고 SDK가 없습니다. 자막라인 자체의 회원 가입은 필요하지 않습니다. 개인 API 연결은 이용자 본인의 OpenAI 계정을 사용하며 API 요금은 해당 계정에 별도로 청구됩니다. 선택 기능인 테스트 서버 연결은 서버 운영자의 API를 사용하므로 개인 API 계정에는 청구되지 않지만, 서버의 공유 사용량 한도로 요청이 중단될 수 있습니다. 이 한도는 정확한 금액 상한이 아니며, 위에서 설명한 서버 집계 카운터는 한도 관리에 사용합니다. API 키, 테스트 접근 코드, 음성, 자막을 개발자에게 문의 자료로 보내지 마십시오.
