# SW-DESIGN-04 — 자막 편집과 영상 미리보기

기준 main 0f43f604643b6e0f1d78ad56363607c4a39bcabb. #93 병합 완료. 시안 A05와 실제 앱의 가장 큰 구조 차이는 별도 전체 화면 재생이었다.

- Android 편집 화면의 파일명 옆에 '영상 함께 보기'를 추가한다. 완료된 원본 연결 작업에서 명시적으로 누를 때만 Native Media3 미리보기를 WebView 위 레이아웃 영역에 연다. 실제 선택 자막 시간부터 정지 상태로 시작, 기존 재생 컨트롤 사용. 기존 전체 화면 미리보기 및 부분 결과 조회 유지.
- 기존 저장 실패 시 신규 영상 열기와 이동을 막는 계약 보존. 동일 작업/선택/화면을 저장 완료 후 다시 검사한다. 저장 성공 시 해당 열린 세션만 저장된 자막 인덱스로 갱신. 저장 실패 시 마지막 저장 자막을 유지하고 기존 저장 실패 UI 노출.
- Native bridge 입력은 jobId 및 위치만 허용. 기존 JobStore의 content URI로 재생. 별도 URL 제공, WebView 파일/콘텐츠 접근 허용, 동영상 복사, 클라우드 전송 및 유료 요청 없음.
- 540dp 미만 편집 가용 높이(키보드·가로/접힘)에서는 신규 열기 제한, 이미 열린 플레이어 닫기/해제. 뒤로가기·다른 페이지 이동·작업 교체·onPause/onDestroy 시 플레이어 해제. 자동 재생 없음.
- 4가지 theme/font 조합에서 실제 Android Media3와 기존 WebView를 함께 캡처하도록 상태 매트릭스 88장으로 확대. 브라우저 회귀: 저장 전 열지 않음, 실패·재시도, 미디어 없는 작업 비활성화, 페이지 이동. 실제 물리 기기/IME/접근성 및 유료 기능은 추가 QA 필요.
- 시안의 기본 내장 플레이어를 항상 표시하지 않고 선택형으로 구현했다. 좁은 화면에서 편집 영역을 보호하기 위한 의도적 차이. 전체 화면 전용 원문/번역 표시 선택 등 별도 기능은 이번 범위에 추가하지 않음.

코드/검증 추가는 PR 상태이며 최신 CI·실제 캡처 성공 후 병합한다. Google Play/웹·서버 배포 직접 실행 없음.
