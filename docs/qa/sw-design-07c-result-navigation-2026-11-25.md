# SW-DESIGN-07-C — Android 결과 탐색 개선

기준 #98 head 96cf9785d174d96183c776801ed8fa90a0dd6878. SW-DESIGN-07 17화면 비교 보고서 A03 후속. #98의 실제 화면 CI 완료 전에 종속 브랜치로 독립 개발.

- 기존 하단 빠른 결과 목록을 상단 작업 선택 옆의 기본 접힌 details로 이동. 단일 결과·결과 없음은 빠른 선택을 숨긴다. 현재 선택 및 최대 3개 실제 결과를 제공하며 전체 결과 수와 전체 select 이용 안내를 표시한다.
- 기존 resultJobSelector와 loadCurrentJob, 저장 flush, 결과별 export, 원본 연결/미연결 상태와 편집 가능 여부는 유지한다. 접힌 상태에서 편집·미리보기·저장 영역의 우선 노출을 유지한다.
- 키보드 열기·닫기, 선택 동기화, 4개 이상 결과의 전체 select 접근, 320/390/800px·라이트/다크·48px 조작 높이 검증 추가. 실제 Android UI-09-A에서 font100/font160의 열기/닫기, 선택 표시, 가로 넘침 및 조작 높이를 확인. 기존 실제 캡처 88장 구성을 변경하지 않는다.
- 검증 성공 전 미병합. #98 병합 후 main 기준 재검증 및 최신 캡처 비교. 실제 지원하지 않는 미리보기 표시 모드, 로컬 모델 및 온보딩 정책을 임의 추가하지 않는다. Google Play 배포 없음.
