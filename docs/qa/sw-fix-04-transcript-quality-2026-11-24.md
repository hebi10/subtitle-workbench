# SW-FIX-04 — 전사 시간 범위·번역 응답 무결성

기준 main: 62d7bf671c8d10c30a02452bf638a5256c9b61b8. 실제 유료 API나 음성 정확도 측정은 수행하지 않았다.

- 웹: 타임스탬프가 누락/음수/역순인 엔트리를 자막으로 만들지 않는다. 화자 정보가 있는 유효 세그먼트를 보존한다. 추출 구간 종료 시각을 전달하여 자막이 실제 추출된 미디어 끝을 넘어가지 않도록 제한한다. 밀리초보다 과도하게 많은 분할을 방지한다.
- Android: 실제 ChunkPlan.extractEndMs를 전달하여 마지막 미디어 경계를 제한한다. 매우 짧은 시간에 많은 자막을 생성하지 않는다. 중첩 단어의 끝 시간을 보존한다.
- 웹 번역: 숫자 정수 ID만 사용하고 중복 ID는 무효 처리한다. 번역 불가/실패 표시, 문자열 아닌 응답 및 누락된 ID는 기존 개별 재시도 대상으로 처리한다. 완전하지 않은/거부 응답은 성공 처리하지 않는다. 성공한 재시도는 이전 실패 표시를 제거한다.
- Android 번역: 숫자 아닌 ID, 번역 실패 표시, 거부 응답을 성공 체크포인트로 저장하지 않는다.
- 검증: Node 회귀, Android TranscriptTest, 기존 웹/Android 기본 CI와 배포 정책 테스트. 한국어/영어/일본어 실음성 정확도, 장편 싱크, 실제 API 비용/모델 품질은 별도 QA.
- 기존 모델, 작업 체크포인트, DB, UI, Play 트랙, 광고/구독 운영값 변경 없음.
