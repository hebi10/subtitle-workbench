# SW-FIX-05 — 장시간 처리 및 체크포인트 복구

기준 main ea1fa9a6bb011d76f10efe7eb1b034b4e0000844. 기존 DB 버전·원본 URI·3시간/26구간 계획·서명/Play 정책 유지.

- 웹: 각 번역 응답의 정상 결과를 현재 페이지 체크포인트에 반영. 후속 묶음 또는 누락 ID 재시도 실패·취소 때에도 앞선 성공 결과와 원문을 보존. 이어하기는 미처리/실패 자막만 재요청. 부분 결과는 분할하지 않고 최종 완료 뒤 기존 자막 길이 기준 적용.
- 웹: 응답 없는 네트워크 오류, 할당량 소진, 30초를 초과하는 Retry-After에 무조건 재요청하지 않음.
- Android: 프로세스 종료 후 유료 요청 단계가 남아 있으면 자동 재전송하지 않고 paused/명시적 이어하기. 저장 완료 상태는 payload 및 플래그와 한 트랜잭션에 기록. 전송 시작 후 I/O 오류 및 HTTP 408은 처리 불확실로 분류. 이미 저장한 전사/번역 구간은 기존 체크포인트로 건너뜀.
- 기존 서버 5xx·단기 429 제한 재시도는 유지. 실제 원격 처리와 과금 확인은 별개이며 중복 과금 0을 보장하지 않음.
- 테스트: Node 부분 번역 보존·선택 재시도·응답 불확실/쿼터/Retry-After, 브라우저 31개 자막 두 배치 실패/복구, Android JVM 불확실 응답, 기기 SQLite 3시간 작업 중간 복구. 기존 180분 합성 영상 26구간 추출 및 강제 종료 트랜잭션 QA는 최종 수동 Android 전체 검사에서 수행.
- 실제 유료 API, 실제 3시간 영상 인식, 배터리·발열은 미검증. 웹 영구 저장은 SW-FIX-06. Play/서버 배포 없음.
