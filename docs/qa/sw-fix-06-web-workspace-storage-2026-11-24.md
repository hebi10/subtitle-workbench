# SW-FIX-06 — 웹 자막 자동 저장·복구

기준 main 8eb0c394924957bb84620e5fd107f1974a3b4c77. 웹만 변경하며 Android SQLite, API 인증·연결·미디어 처리 및 Play 배포 정책은 유지한다.

- 최초 기본 꺼짐. 명시적으로 켜면 IndexedDB에 최신 자막, 파일명/길이, 싱크, 화자, 완료/미완료 번역 상태를 저장한다. 원본 미디어·Object URL·API 키·Worker 주소·실행 취소 이력·API 원문 오류는 저장 대상 제외. 자막 자체는 암호화하지 않는다.
- 저장 성공은 트랜잭션 완료 기준. 용량/접근/충돌 오류를 표시하며 이전 완료 저장을 지우지 않는다. 200개 작업/8Mi UTF-16 문자 한도 초과는 오류 처리하며 자동 삭제하지 않는다.
- 재방문 복구는 새 API 요청을 실행하지 않는다. 원본 미디어 재연결 및 인증 정보 입력은 사용자 선택. 미완료 번역은 기존 선택 재시도 경로를 사용한다.
- 다른 탭에서 수정 또는 삭제된 작업을 덮어쓰지 않도록 revision 비교를 같은 readwrite 트랜잭션에서 수행한다. 저장 기록 삭제는 사용자 확인 후 저장을 끄며 현재 탭 작업은 유지한다.
- 음성 인식 완료 뒤 원문 및 각 번역 응답 체크포인트를 저장하고 다음 요청 전에 트랜잭션 종료를 기다린다. 음성 인식 완료 전, 갑작스러운 종료로 커밋되지 않은 편집 및 브라우저 데이터 삭제는 복구를 보장하지 않는다.
- Node 허용 필드/실패 테스트, Playwright 실제 IndexedDB 저장/새로고침/삭제/다중 탭 충돌 및 부분 번역 체크포인트를 검증한다. 기존 UI 회귀 테스트 유지. 실제 사용자 브라우저·장시간 사용 검증은 별도.
- Play 배포 및 서버 변경 없음.
