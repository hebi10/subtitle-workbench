# SW-FIX-07 — 자막 편집 및 미리보기 안정화

기준 main 8eb0c394924957bb84620e5fd107f1974a3b4c77. SW-FIX-06 PR #86과 병행한 별도 브랜치이며, #86의 CI 및 병합을 선행 확인한다.

- 공유 편집 모듈: 최소 2ms 분할 조건 및 유효 텍스트 확인. 밀리초 정수 경계로 두 구간 모두 양수 길이 유지. Unicode 글자 단위 분할(지원 브라우저의 Intl.Segmenter, 구형 환경은 코드포인트), 실패 표시 보존. 웹/Android 분할 버튼 비활성화. 수동 번역을 edited로 표시하여 기존 선택적 재시도에서 보존.
- 웹/Android 플레이어: 편집·불러오기 시 시간 인덱스를 구축하고 재생 중 O(log n) 조회. 겹치는 자막의 기존 시간순 우선순위 및 시작 포함/끝 제외 규칙 유지. 실패 표시 대신 원문 표시. 웹 재생 중 기존/새 활성 행만 갱신, 미디어 없을 때 이동 차단. Android 저장 자막 로드 실패를 안내하고 동일 텍스트 반복 갱신 최소화.
- 회귀 테스트: 초단기 자막, Unicode, 수동 번역, 20,000개 자막의 임의 탐색, 중첩·경계·역탐색. 실제 성능 향상 수치나 기기 영상 재생은 최종 QA 전 보장하지 않는다.
- 기존 UI 레이아웃·번역 모델·원본 파일·DB·배포 정책 유지. Play 변경 없음.
