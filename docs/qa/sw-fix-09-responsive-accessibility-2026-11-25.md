# SW-FIX-09 — 폴더블·태블릿·접근성 개선

기준 main 56c3ae0aae8294aa8e69dacac17e38b833c9d9d7. SW-FIX-06 병합본 기준 독립 브랜치. #87·88과 통합 검증 필요.

- Android WebView: 고정 하단 메뉴의 실제 높이를 ResizeObserver로 관찰하고 본문 하단 여백 및 scroll-padding에 적용. 화면 크기와 글꼴에 따라 메뉴가 커져도 마지막 작업/편집 조작이 메뉴 뒤에 가려지지 않도록 처리.
- 하단 메뉴 텍스트 줄바꿈 허용, 최소 터치 높이 48px 유지. 기존 탭/초점/색상 체계 유지.
- 높이 500px 이하(가로 모드, 키보드 등)에서 편집 저장/페이지 안내 영역을 일반 문서 흐름으로 전환. 크기 변경 시 선택된 입력의 가시 영역 확인, 현재 입력·편집 내용 유지.
- 웹: 넓고 낮은 뷰포트에서도 미리보기 카드의 sticky 고정을 해제하고 영상 최대 높이를 제한.
- 회귀: 320px 큰 메뉴 라벨 및 늘어난 메뉴 높이, 800×360 회전 모의, 입력 초점/내용/스크롤 여유, 1280×360 웹, 기존 반응형 매트릭스.
- Playwright 모의 Android WebView는 실제 Fold·태블릿·IME·TalkBack 검증을 대체하지 않는다. 최종 Android 전체 QA에서 실제 기기 및 글꼴 160% 확인. 원본/DB/모델/광고/Play 배포 정책 변경 없음.
