# UI-09-C — 새 자막 작업 화면

기준: 2026-11-11 · Android WebView `videoView`
저장소: https://github.com/hebi10/subtitle-workbench

## 목표
파일 자동 자막, 기기 마이크, 오프라인 Vosk의 진입 동선을 작업 유형 중심으로 정리한다. API 연결/원본 파일/비용·전송 조건에 관한 정보를 정확히 분리한다. 2-A에서 구현된 기능·ID를 재구현하지 않는다.

## 구현
1. 기존 첫 사용 안내는 유지하고, 안내가 숨겨진 재방문 사용자에게만 compact한 작업 방식 선택 3항목(영상·음성 파일 / 마이크 인식 / 오프라인 AI)을 보여 준다. 각각 기존 버튼으로 포커스·스크롤해 사용자가 작업 유형을 먼저 선택한다.
2. API 연결이 없으면 파일 선택으로 곧바로 이동하지 않고 기존 연결 설정 화면으로 이동한다. 선택 카드 상태도 저장된 키·연결 검사 상태에 맞춰 표시한다.
3. 파일 자동 자막은 개인 API 또는 테스트 서버 연결이 필요하고 SRT/VTT/JSON 자막 가져오기는 API 없이 가능하다는 차이를 적시한다.
4. 기기 마이크는 API 불필요, GPT 실시간은 연결 및 요금·전송 확인이 필요함을 명확히 구분한다.
5. Vosk는 앱 안에서 모델을 다운로드할 때는 인터넷 연결이 필요하지만 설치 후 로컬 인식에는 개인 API·인터넷이 필요하지 않다는 조건을 유지한다.
6. 기존 `firstRunGuide`, `preparedJobs`, `pickVideo`, `importSubtitles`, `openOnDevice`, `openCloudLive`, `openOfflineModel`, `connectionCard`·API 데이터 계약을 변경하지 않는다.
7. 320/390/800px, 라이트·다크, 100/160% 글꼴에서 오버플로·터치 영역을 확인하고 Playwright 및 API35 실제 Android 에뮬레이터 캡처로 시각적 회귀를 검증한다.

## 안전 경계
Native 인식, API 키 저장, 선택 조건, 유료 호출, 모델 설치·삭제, 원본 미디어, Android 서명, AAB, Google Play 등록정보 및 테스트 트랙은 수정하지 않는다. PR의 검증과 캡처 검수가 성공하면 `[skip-play]`로 병합한다.

## 검증 및 증빙
- 기존 2-A/1-B와 통합 QA 테스트 재실행
- 연결 저장 있음/없음에서 파일 선택 상태, 자막 가져오기, 온디바이스·GPT·Vosk 진입 확인
- 로컬 사용자 데이터 또는 유료 API를 사용하지 않는 fixture 테스트
- Android 15(API35) 실제 에뮬레이터 라이트·다크/100·160% 캡처 및 Google Drive 저장
- 물리 기기의 마이크·TalkBack·IME·유료 인식 성능은 별도 검증 항목
