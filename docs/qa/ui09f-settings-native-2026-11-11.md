# UI-09-F — 설정 및 Native 인식 3종 리디자인

기준일: 2026-11-11
저장소: https://github.com/hebi10/subtitle-workbench
기준: UI-09-A Android15 상태별 QA, 기존 Editorial Studio 2.0 2-E·2-F 설계 및 Google Drive UI-09 개선 계획.

## 목적
연결 상태와 다음 영상의 기본값을 실제 설정 폼과 명확하게 분리하고, 음성 인식 3종의 준비/실행/저장 단계 및 현재 필요한 행동을 먼저 볼 수 있게 조정한다. 권한·키·요금·라이선스·네트워크 사실은 숨기거나 줄여 잘못 안내하지 않는다.

## 웹 Android 설정
- 설정 요약의 연결 상태/검증 배지를 한 행으로 정리하고, 실제 설정 편집 상세 섹션을 별도 제목으로 구분한다.
- 화면 너비 619px 이하에서 한 열로 전환해 390px·160% 글꼴에서도 텍스트/버튼이 과도하게 압축되지 않게 한다.
- 암호화된 키 저장, 테스트 릴레이 주소/접근 코드, 연결 검사, 저장된 기본값과 아직 저장하지 않은 수정 상태, 개인정보처리방침은 기존 요소/ID·기능을 유지한다.

## Native 온디바이스
- 서비스/언어 지원의 실제 상태를 1단계 언어 준비 패널에 먼저 표시하며, 마이크 시작·중단·확정 저장은 기존 2/3단계에 유지한다.
- Android SpeechRecognizer의 지원/다운로드/언어 권한 검사·오류 대응 흐름은 변경하지 않는다. 언어 모델 다운로드 요청은 Android 13 이상에서 가능함을 도움말로 유지한다.

## Native GPT 실시간
- 연결 요약의 전송 대상·API 과금(개인 API) 또는 공용 테스트 사용량 한도(테스트 릴레이)를 인식 시작 전에 간결하게 항상 노출한다.
- 더 긴 네트워크·요금 설명은 별도의 접을 수 있는 도움말로 제공한다.
- 실제 키/서버 목적지, 유료 API 전송 및 마이크 권한은 이전 로직 그대로다. 인식 시작 버튼을 앱이 임의로 실행하지 않는다.

## Native Vosk
- 모델의 설치 여부·사용 용량 또는 다운로드 필요 상태를 먼저 표시한다. 선택 모델의 기술 설명과 네트워크 설치 요건은 접힌 상세 도움말에서 확인한다.
- 파일 선택을 최우선 버튼으로 유지하고, 60분 제한/원본 파일 권한 상세는 접힌 도움말로 이동한다.
- 체크섬·손상 감지/삭제 확인·다운로드·실제 인식·저장 로직은 수정하지 않는다.

## 검증 기준
1. Node/Playwright 전체 WebView 테스트, Android JVM/Lint/debug APK, API35 실제 Android 기기 계측 테스트.
2. 기존 3단계 진행 표기·48dp+ 버튼·상태 텍스트·접힌 도움말 접근 및 탭/포커스 동작 테스트.
3. 320/360/390/432/800px, 라이트·다크·100/160% 글꼴, 줄바꿈과 가로 넘침, 개인정보/요금 안내 보존.
4. 최신 실제 Android 원본 캡처와 Chromium 캡처 출처 구분, Google Drive 보관.
5. 최종 CI와 시각 검수 통과 시 [skip-play] 병합. Android Keystore/SQLite/마이크 권한·전사·다운로드 및 Play AAB/서명/트랙은 변경하지 않음.
6. 물리적인 휴대폰 TalkBack·실제 마이크 음성·유료 모델 품질은 이번 자동 QA로 입증되지 않는다.

## 최초 CI 피드백 및 수정
초기 Verify web and Android 웹 테스트에서 ‘상세 설정’ 제목에 클래스가 있는 정상 HTML을 테스트 정규식이 잘못 탐지했고, 390px 기본 화면 높이가 기존 1100px 상한을 넘어 1206px으로 측정됐습니다. 제목 검사는 태그 속성을 허용하도록 보정했으며, 361~619px에서는 1열 설정 카드 안에 상태 요약과 관련 변경 버튼을 좌우로 배치해 전체 높이를 줄였습니다. UI 상한은 완화하지 않고 기존 장문 도움말과 연결 상태 텍스트를 보존합니다. 360px 이하는 1열의 전체 너비 입력 기준을 유지합니다.
