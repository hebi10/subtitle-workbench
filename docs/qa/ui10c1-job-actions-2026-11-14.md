# UI-10-C1 — 작업 관리 상태별 주요 행동 정리

기준 소스: BRAND-01-FINAL 병합 main 4f8d4c74fe878a6d493881e81d2d669bc815229b.
기획 근거: Drive 030_UI-10 (Android 작업 관리 02), 031_UI-10-00 정정 보고서.
범위: 기존 WebView 작업 카드의 행동 순서와 사용 가능 상태만 정리. API·JobStore·자막 파일 포맷·Play 배포 설정은 변경하지 않음.

## 상태별 1순위 행동

- 준비됨: 작업 관리 목록에서는 '준비 확인', 준비 작업 편집 카드에서는 연결이 유효할 때 '생성 시작'.
- 진행/대기: '일시정지' (상태별 '이어하기' 동시 표시 금지).
- 일시정지: 현재 연결이 일치하고 인증 정보가 있으면 '이어하기', 아니면 'API 설정 확인'.
- 오류: 이어하기가 유효하면 '이어하기', 아니면 'API 설정 확인'. 실제 오류 사유는 카드에 유지.
- 완료: '자막 편집'. '결과 보기', SRT 저장, 원본을 보존하는 기록 삭제/취소는 보조 작업으로 유지.
- 작업 실행 중 해당 버튼이 비활성화되면 사용 불가능한 동작을 대표 행동으로 강조하지 않음.

## 데이터·디자인 보존

- JobStore 저장 진행률/저장 구간 기반이며 임의 남은 시간, 필터/검색/수동 정렬을 추가하지 않음.
- 기존 준비 작업 설정 폼과 수정 중 초안, 4개/페이지, 페이지 포커스, 완료 삭제 2단계 확인 유지.
- DOM ID, Native Bridge pause/resume/loadJob/export/deleteJob, 앱 서명·패키지·키 저장소, 원본 파일 보존.
- 기존 색상/타이포/테마/평면 아이콘 사용. 대표 행동은 가로 1줄, 보조 버튼은 기존 그리드 유지. 그림자·곡률 추가 없음.

## 검증 게이트

1. Node/Playwright: 준비·진행·대기·일시정지·오류·완료별 대표 버튼이 활성 상태 하나인지 확인.
2. API 미연결 및 연결 전환: 연결되지 않은 이어하기 금지, 설정 안내, 준비 편집 DOM 재사용 시 버튼 정합.
3. 작업 페이지 4개/페이지, 완료 기록 삭제 확인/취소, 원본 보존, SRT 내보내기 기존 동작 유지.
4. 320/390/800px, 라이트/다크, 터치 영역 48px, 화면 가로 넘침 방지; Android 15(API 35) Emulator Smoke.
5. 최신 HEAD의 Verify web and Android, Android Emulator Smoke, OPS-07, GitGuardian 성공 및 리뷰 해소 후만 main 안전 병합.
