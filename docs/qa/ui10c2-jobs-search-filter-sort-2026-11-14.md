Google Drive UI-10 작업 관리 화면(02) 및 UI-10-00 정정 기준을 반영합니다.

## 범위

- `jobsView`에 접고 펼 수 있는 파일명 검색·상태 필터·정렬 컨트롤 추가
- 검색은 현재 JobStore에서 전달한 `job.name` 문자열에 대한 대소문자 구별 없는 부분 일치
- 상태 필터: 전체 / 진행·대기 / 준비 / 일시정지 / 오류 / 완료. 준비는 `paused && stage === 'ready'`로 구분
- 정렬: 기존 상태 우선(기본), 생성일 최신순, 생성일 오래된순. Java JobStore의 `createdAt` 값(Unix ms)만 사용
- `createdAt` 없는 이전·테스트 레코드는 임의 시각을 생성하지 않고 날짜 정렬에서 맨 뒤, 동일 날짜는 수신 순서 유지
- 결과에만 4개 단위 페이지네이션 적용, 조건 변경 시 첫 페이지, 상태 새로고침·삭제 후 페이지 범위 자동 보정
- 전체 작업 건수·상태 요약은 필터와 무관하게 원본 JobStore 목록 기준 표시
- 필터 결과가 0개인 상태와 실제 작업 자체가 0개인 상태는 별도로 안내
- 기존 준비 작업 선택기, 준비 설정 초안, Native Bridge, 저장·복구, 자막 미디어, 삭제 확인·SRT export 기능 보존
- 입력 컨트롤은 기본 접힘으로 화면 높이 보존, 320/390/800px·라이트/다크에서 48px 터치 목표 유지
