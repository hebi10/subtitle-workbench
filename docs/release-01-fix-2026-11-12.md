# RELEASE-01-FIX — Play 비공개 테스트 사전차단·스토어 정합성 복구

검증 기준: 2026-11-12 KST. 앱: com.haebi.subtitle / ko-KR.
실행 범위: Play 등록정보의 **승인된 전체 설명·앱 아이콘·대표 그래픽**에 한정하며 앱 본체/AAB/서명, 내부 테스트/alpha 트랙, 개인 API 키, 테스트 서버 설정은 변경하지 않는다.

## 근거 기록

- #42591561473: internal versionCode 21 등록과 재조회는 성공했으나 alpha 승격에서 HTTP 400 실패.
- #42738823793: 승격 재시도에서 \`validate_edit HTTP 400 (status=INVALID_ARGUMENT)\` 확인. 원인을 특정 정책 항목으로 단정할 근거는 없음.
- #42794411540: 2026-11-10 internal versionCode 22 / completed / api_committed_and_verified.
- #42955733745: Play API 감사 당시 alpha 트랙 릴리스 없음. 제목/짧은 설명 일치, 전체 설명·아이콘·대표 그래픽 불일치, 스크린샷 5장.
- #43002977929: 2026-11-11 STORE-05 승인된 Android 실화면 8장 재등록 및 새 Edit의 SHA-256 재조회 성공. 이 작업은 설명·아이콘·대표 그래픽을 수정하지 않았음.

## 등록정보 복구 정책

- 승인 기준은 \`docs/play-store/listing-ko.json\`의 \`fullDescription\`과 \`assets/play-store/ko-KR/manifest.json\`의 \`icon.png\`, \`feature-graphic.png\` 해시.
- 원격 제목과 짧은 설명이 저장소와 다르면 **즉시 중단**. 다른 사람이 수정한 값 덮어쓰지 않음.
- 원격 phoneScreenshots 해시 8장이 STORE-05 기준과 다르면 **즉시 중단**. 이미 승인된 8장 반복 업로드 금지.
- 변경이 필요 없는 항목은 삭제·재업로드하지 않는다. 변경이 전혀 없으면 Edit을 커밋하지 않는다.
- 불일치한 전체 설명은 PATCH, 불일치한 아이콘·대표 그래픽만 DELETE + PNG 업로드한다.
- Play Edit 커밋 전과 이후 별도 새 Edit에서 설명·아이콘·그래픽·스크린샷 SHA를 대조한다.
- 승인된 GitHub main 커밋 제목이 정확히 \`store: RELEASE-01-FIX approved brand and description [listing-reconcile]\`인 경우에만 \`Play internal release\`의 \`reconcile\` 경로를 사용한다. 기존 WIF 신뢰/검증·변경 중 main HEAD 재확인·Play 직렬화·아티팩트 보고를 그대로 유지한다.
- 신규 AAB 생성, versionCode 할당, internal PUT, alpha 승격 단계는 해당 모드에서 실행되지 않는다.
- 보고서의 \`api_committed_and_verified\`는 Google Play API 재조회 완료를 뜻하며, Play Console 심사·게시·테스터 설치를 증명하지 않는다.

## 비공개 테스트 실패의 별도 차단

Google 공식 지원 문서는 내부 테스트의 앱 설정 완료 전 시작을 허용하지만, 비공개 테스트는 앱 설정 완료를 요구한다. 앱 설정 미완료는 우선 점검 후보이며, 실제 INVALID_ARGUMENT 원인 확정은 **Play Console의 해당 앱**에서 필요하다.

Play Console에서 직접 확인해야 할 항목:
1. 대시보드: 앱 설정 완료 여부, 정책/검토/출시 차단 배너, 게시 개요 대기 중 변경사항.
2. 앱 콘텐츠: 개인정보처리방침, 데이터 보안, 콘텐츠 등급, 앱 액세스, 대상 연령, 광고 선언 등 해당 앱에 요구되는 항목.
3. 비공개 테스트: 정확한 alpha 트랙과 국가/지역, 테스터 이메일 목록 또는 Google 그룹, 피드백 경로, 실제 테스트 릴리스 생성 가능 여부.
4. 심사 접근: 필요한 테스트 서버의 실제 HTTPS 주소·반복 사용 가능한 접근 코드·클라우드 전사 기능 작동. 코드나 개인 OpenAI 키는 GitHub·공개 Drive·로그에 기재하지 않는다.
5. 검토 대기/관리형 게시: Play API의 Edit 커밋 성공과 스토어 출시·테스터 노출은 별도 단계로 확인한다.

Google 공식 문서:
- https://support.google.com/googleplay/android-developer/answer/14151465
- https://support.google.com/googleplay/android-developer/answer/9845334
- https://developers.google.com/android-publisher/edits

## 최종 판정 기준

- 스토어: CI·Android 15·원격 Play API의 fresh listing/hash readback 모두 성공하고, Console 검토 항목을 별도 확인한 경우에만 완료.
- 비공개: Console 준비 완료, 최신 internal 정확한 versionCode 확보, alpha 승격과 fresh readback 성공, 테스터 opt-in/설치 확인까지 필요.
- 오류 발생 시 기존 내부 버전의 무검증 재승격, 같은 8장 이미지 반복 제출, 전체 listing 덮어쓰기는 금지.
