01 / SOURCE

영상·연결 준비

영상 선택, API 연결, 언어 설정을 확인하세요.

영상 원본은 브라우저에서 처리합니다. 추출한 음성과 자막 텍스트는 전사·번역을 위해 OpenAI 또는 선택한 Worker로 전송됩니다.

API 연결 방식
연결 방법과 준비사항

직접 연결: 본인의 OpenAI API 키로 바로 사용합니다.

Worker 연결: 미리 구성한 중계 서버를 사용합니다. 본인의 API 키와 관리자에게 받은 Worker URL이 필요합니다.

API 키는 OpenAI에서 발급할 수 있습니다. API 사용 요금은 ChatGPT 구독과 별도입니다.

사용자 API 키를 제한된 Worker를 통해 OpenAI로 전달합니다.

API 키는 저장하지 않고 현재 탭에서만 사용합니다. 새로고침 후 다시 입력해 주세요.
