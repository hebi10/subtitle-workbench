AI Subtitle Studio

영상은 업로드하지 않고 브라우저 안에서 오디오를 추출합니다.

결과와 편집 내용은 현재 페이지에서 유지됩니다. 닫기 전에 파일을 내려받으세요.

Step 01

소스와 연결

영상 원본은 브라우저에서 처리합니다. 추출한 음성과 자막 텍스트는 전사·번역을 위해 OpenAI 또는 선택한 Worker로 전송됩니다.

API 연결 방식
연결 방법과 준비사항

직접 연결: 본인의 OpenAI API 키로 바로 사용합니다.

Worker 연결: 미리 구성한 중계 서버를 사용합니다. 본인의 API 키와 관리자에게 받은 Worker URL이 필요합니다.

API 키는 OpenAI에서 발급할 수 있습니다. API 사용 요금은 ChatGPT 구독과 별도입니다.

사용자 API 키를 제한된 Worker를 통해 OpenAI로 전달합니다.

API 키는 저장하지 않고 현재 탭에서만 사용합니다. 새로고침 후 다시 입력해 주세요.

자막 언어

번역을 끄면 원문 자막만 생성합니다.

고급 설정
인식과 번역 모델

STT는 음성을 글로 바꾸는 음성인식 모델입니다. 처음에는 기본값을 사용하세요.

오디오 분할

dB 값이 낮을수록 더 작은 소리를 무음으로 봅니다. 패딩은 문장 잘림을 줄이는 조각 앞뒤 여유 시간입니다.

자막 길이와 읽기 속도

CPS는 1초에 읽는 글자 수입니다. 값을 낮추면 자막을 더 천천히 읽을 수 있게 나눕니다.

영상이나 오디오를 선택하면 이곳에서 미리 볼 수 있습니다.

자막을 생성하거나 파일을 불러오면 여기에 표시됩니다.
